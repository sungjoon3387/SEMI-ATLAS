# Semi Atlas

반도체 산업 참조 + 매일 갱신되는 뉴스 스캔. BEOL Atlas 옆에 두는 한 장짜리 페이지입니다.

```
semi-atlas/
├── index.html        페이지 (탭 4개: 뉴스 / 삼성 제품군 / 반도체 개요 / 업황)
├── content.js        고정 콘텐츠 — 여기만 고치면 내용이 바뀝니다
├── collect.py        뉴스 수집기 (표준 라이브러리만, pip 설치 불필요)
├── run_daily.bat     윈도우 작업 스케줄러용
├── data/
│   ├── news.js       페이지가 읽는 파일 (자동 생성)
│   └── archive/      일자별 스냅샷 → 14일 추이 계산에 사용
└── .github/workflows/daily.yml   PC 없이 돌리는 경우
```

---

## 1. 지금 바로 확인

```
cd semi-atlas
python collect.py
```

끝나면 `index.html` 을 브라우저로 열면 됩니다. 별도 서버 없이 `file://` 로도 동작합니다.

수집이 0건이면 기존 데이터를 덮어쓰지 않고 종료합니다. 매일 무인 실행 중 일시적 네트워크
장애가 나도 페이지가 비지 않습니다.

---

## 2. 매일 자동 실행 — 방법 두 가지

### A. 로컬 PC (PC를 켜두는 경우)

작업 스케줄러 → 작업 만들기

| 항목 | 값 |
|---|---|
| 트리거 | 매일 오전 7:00 |
| 동작 | 프로그램 시작 |
| 프로그램 | `run_daily.bat` 전체 경로 |
| 시작 위치 | `semi-atlas` 폴더 경로 |
| 옵션 | "사용자가 로그온했는지 여부에 관계없이 실행" 체크 |

PowerShell 한 줄로 등록해도 됩니다.

```powershell
schtasks /create /tn "SemiAtlas" /tr "C:\경로\semi-atlas\run_daily.bat" /sc daily /st 07:00
```

실행 기록은 같은 폴더의 `collect.log` 에 쌓입니다.

**폰에서 보려면** 같은 와이파이에서 PC에 서버를 띄웁니다.

```
python -m http.server 8080 --bind 0.0.0.0
```

폰 브라우저로 `http://<PC의 IP>:8080` 접속. 방화벽에서 8080 인바운드를 열어야 하고,
PC가 꺼지면 안 열립니다.

### B. GitHub Pages (권장 — PC를 안 켜도 됩니다)

1. 이 폴더를 GitHub 저장소로 올립니다 (공개/비공개 무관, Pages는 공개 저장소가 편합니다)
2. Settings → Pages → Source를 `main` 브랜치 루트로 지정
3. Actions 탭에서 `daily-news` 워크플로를 한 번 수동 실행해 동작 확인

매일 KST 06:00에 깃허브 서버가 뉴스를 모아 커밋합니다. 폰에서는
`https://<계정>.github.io/<저장소>/` 를 열고 홈 화면에 추가하면 BEOL Atlas와 같은 방식으로
쓸 수 있습니다. `<head>` 에 manifest가 들어 있어 크롬에서는 전체화면 앱으로 설치됩니다.

한 가지 주의: 저장소에 60일 이상 아무 활동이 없으면 깃허브가 예약 워크플로를 자동으로
멈춥니다. 매일 커밋이 발생하니 실제로는 걸릴 일이 거의 없습니다.

## 3. 내용 고치기

전부 `content.js` 한 파일에 있습니다. HTML은 건드릴 필요 없습니다.

- `me` — 상단에 표시되는 본인 소속·담당
- `samsung` — 부문 → 사업부 → 항목. `hot: true` 를 주면 "담당 접점" 표시가 붙습니다
- `basics` — `rows`(정의 목록) 또는 `steps`(번호 목록) 중 하나를 쓰면 알아서 렌더링됩니다
- `market` — 스냅샷, 변수, 사이클, 지표 링크

## 4. 뉴스 피드 조정

`collect.py` 상단 `FEEDS` 를 고칩니다. 검색어를 바꾸는 게 가장 쉽습니다.

```python
{"label": "하이브리드 본딩", "url": gnews("하이브리드 본딩 범프리스"), "w": 3},
```

`w` 는 가중치입니다. 크면 상단 헤드라인으로 올라올 확률이 높아집니다.
분류 규칙은 `CATS`, 본업 관련 부스트 키워드는 `CORE_KWS` 에 있습니다.
